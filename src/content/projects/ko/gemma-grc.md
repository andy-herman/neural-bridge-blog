Gemma GRC는 제 책상 위 맥 미니에서 전부 로컬로 돌아가는 거버넌스·리스크·컴플라이언스(GRC) 어시스턴트입니다. 구글의 소형 오픈 모델 Gemma가 제 노트와 강의 자료로 만든 라이브러리를 근거로 답하고, 모든 주장에 근거 문단을 인용하며, 라이브러리에 답이 없으면 없다고 말합니다.

동시에 실험실이기도 합니다. 모든 변경은 가설을 먼저 적어 두고 한 번에 하나의 변수만 바꾸는 실험으로 진행하며, 고정된 질문 세트를 다른 계열의 모델이 채점합니다.

## 작동 방식

```
볼트 노트 → 기밀성 게이트 → 출처 정보가 붙은 청크
          → 하이브리드 검색: 튜닝된 임베딩 + BM25
          → Gemma가 [n] 인용과 함께 답하거나, 무엇이 빠졌는지 밝힘
```

## 실험에서 알게 된 것

- **제 노트로 모델을 파인튜닝하자 오히려 나빠졌습니다.** 지어낸 내용이 들어간 답변이 다섯 개 중 하나에서 거의 절반으로 늘었습니다. 말투는 배웠지만 사실은 배우지 못했습니다.
- **성과는 검색에서 나왔습니다.** 5점 척도에서 답변 품질이 거의 1점 올랐습니다.
- **가장 큰 단일 개선은 검색 모델에서 나왔습니다.** 언어 모델보다 약 120배 작은 모델을 9분 동안 파인튜닝하자, 정답 문단이 상위 4개 안에 드는 비율이 71%에서 79%로 올랐습니다.
- **가장 어려운 문제는 측정이었습니다.** 한 채점 모델은 거의 모든 것을 통과시켰고, 다른 하나는 수리하기 전까지 정답이 그대로 적힌 원문 문단의 62%를 놓쳤습니다.

## 거버넌스

수집 파이프라인은 페일 클로즈드(fail-closed) 방식입니다. 다음 중 하나라도 있는 노트는 코퍼스에 들어오지 못합니다.

- '공개' 외의 분류 라벨
- 비공개·기밀 플래그나 태그
- 취급 표시

줄바꿈 형식이나 프런트매터의 예외로 게이트가 뚫리지 않습니다. 모든 청크에는 출처 등급이 붙고, 공개 문서와 제가 직접 쓴 글만 기기 밖으로 나가거나 학습에 쓰일 수 있습니다.

청크 ID는 내용 해시입니다. 검색 인덱스에는 그것을 만든 코퍼스와 모델의 지문이 찍혀 있어, 다른 것과는 함께 로드되지 않습니다.
